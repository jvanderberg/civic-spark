# Agent screenshots

The agent composer accepts pasted images while focused and provides an Attach images file picker. Text paste remains native, including text in mixed clipboards. Attachments never send automatically. PNG, JPEG and WebP are supported: at most four images, 2 MiB each, 4 MiB combined, 8,000 pixels per side and 25 megapixels per image. Remove controls work without hover. Drafts follow the existing composer lifecycle: retained through workspace tabs, menus, resizing and socket reconnect; unsent drafts are not stored across a full page reload.

Image-only and mixed messages use native Claude SDK streamed user image blocks and OpenCode file parts with validated data URLs. Fixed model choices are unchanged. The exact GLM model is `openrouter/z-ai/glm-5.3-flash`; [OpenRouter describes it as native multimodal](https://openrouter.ai/z-ai/glm-5.3-flash), and the pinned OpenCode 1.18.31 registry reports image input. The runner checks that registry before sending images and reports unsupported image input without selecting another model. Anthropic’s [vision examples explicitly use `claude-opus-5`](https://platform.claude.com/docs/en/build-with-claude/vision). Claude follows the [official SDK streaming input protocol](https://code.claude.com/docs/en/agent-sdk/streaming-vs-single-mode).

Image drafts remain available after failed or stopped turns. Successful completion clears the submitted images; reconnect never resends a prompt. IDs correlate image turns and prevent duplicate replayed submissions. Provider session IDs and saved credentials remain in their existing locations.

The browser decodes the file before accepting it. Both server and runner validate strict schemas, canonical base64, decoded sizes, container signatures and dimensions; PNG chunks also require correct CRCs. Remote URLs, paths, SVG and unknown input fields are rejected. Images enter only structured private conversation fields, never project files, Git, Share or exports. The Sprite journal is mode 0600 outside the project. Browser, management replay and Sprite journal share a 500-event / 10 MiB total retained-history cap, so old history is evicted across many turns. Provider-native context retention remains managed by each coding harness. The management process never decodes pixels or executes participant code.

Integration requires the shared WebSocket `maxPayload` to be **6 MiB** in `apps/server/src/app.ts` (owned by the preview change). Terminal input retains an explicit 64 KiB bound. Agent input, queued messages, output events and buffered replay have separate bounds; only authenticated workspace-owner sockets receive image history, and execution/access checks run again before forwarding each prompt. No upload endpoint is introduced.

Validation is local and uses no paid inference or participant resources. `npm run test:agent-images` runs the pinned Claude SDK 0.3.273 and OpenCode 1.18.31 against loopback fake APIs, asserting actual outgoing image bytes, image-only/mixed turns, original image context on resume and unchanged model/session IDs. Prepare its locked OpenCode binary with `npm ci --prefix packages/agents/runtime`. The protocol/bridge tests cover malformed images (including a corrupt PNG checksum), caps, large replay, owner isolation, revoked access and unsupported capabilities. Agent browser coverage exercises clipboard-event emulation, file input, removal, failed-send and reconnect retention, and 360/390/desktop/300px screens in both themes. The existing keyboard suite also holds the layout viewport at 844px while independently shrinking/panning the visual viewport to 300/350px, with an image draft, focused typing, Remove and Send all reachable; compact styling queries the measured agent container. Native iOS/Android clipboard, keyboard and picker behavior and live vision inference remain unverified.

The thumbnail/file-input/remove geometry is adapted from pinned T3 Code `ChatComposer.tsx` at `b12c92f695a6b12116fb2cda40d610bdbe2a9566`, with touch targets enlarged to 44px. Upstream attribution remains in `apps/web/src/vendor/t3code/`.
