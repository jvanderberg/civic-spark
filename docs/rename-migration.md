# Civic Spark namespace migration

The complete source rename is a breaking change. Earlier environment names, commands, runtime directories, cookies, browser storage keys and Git metadata names are no longer read as aliases. This revision changes tracked source only: it does not rename existing Sprites, migrate participant data or credentials, restart services, change external memory pages or rewrite Git history.

Fresh installations use `.env.example`, the committed runtime setup and the namespaces below. Existing installations must remain on their working revision until an operator has inventoried and backed up state and approved a migration. No automated migration tool is implemented or verified.

| Surface | Current namespace | Existing-installation consequence |
| --- | --- | --- |
| Server configuration | `CIVIC_SPARK_AUTH_MODE`, `CIVIC_SPARK_PORT`, `CIVIC_SPARK_DATA_DIR`, `CIVIC_SPARK_EMAIL_PROVIDER`, `CIVIC_SPARK_EMAIL_FROM`, `CIVIC_SPARK_AUTH_REQUESTS_PER_MINUTE`, `CIVIC_SPARK_ENABLE_SPRITES`, `CIVIC_SPARK_SPRITE_ORG` | Translate deployment and ignored local settings explicitly. Earlier variables are ignored; defaults select email mode, `.data`, port 4311 and disabled cloud workspaces/email delivery. Preserve the intended data root and auth mode. |
| Provider configuration | `BETTER_AUTH_*`, `SMTP_*`, `RESEND_API_KEY` | These provider identifiers are unchanged. Keep values in the existing secret store; never add credentials to source. |
| Runtime package and CLI | `civic-spark-sprite-runtime`; `civic-spark git …` / `civic-spark preview …` | Launchers and native harness paths must be updated together using the committed, locked setup. |
| Sprite identity | `civic-spark-…` (dedicated tests: `civic-spark-smoke-…`) | Adapters reject names outside the new prefix. Updating persisted metadata alone does not rename a cloud resource; a provider-supported migration or approved replacement with verified state transfer is required. |
| Private runtime | `/home/sprite/.civic-spark-agent` | Preserve `conversation.json`, provider session IDs, environment settings, integration approvals and private configuration before changing paths. Native saved keys remain outside project files; never require repasting them merely to perform this migration. Running turns must finish before coordinated runtime/server changes. |
| Terminal and preview | `civic-spark-workspace`, `civic-spark-web-preview`, `/__civic_spark_open` | Existing tmux sessions, managed processes and old preview links do not switch automatically. Keep recovery access; reconnect through Open preview after migration. |
| Git metadata | `refs/civic-spark/base`, `refs/civic-spark/team-incoming`, `refs/civic-spark/share/*`, `refs/civic-spark/recovery/*`; `.git/civic-spark-agent-merge.json`, `.git/civic-spark-recovery/` | Preserve each ref's exact commit and all recovery files/receipts. Baseline fallback to `origin/main` or `HEAD` is not a verified migration. Finish pending merges/rebases first; never rewrite published history or force-push. New commits use Civic Spark author labels; existing commits remain intact. |
| File locks and transfer paths | `/home/sprite/.civic-spark-file-lock`, `.civic-spark-*`, `/tmp/civic-spark-*` | Do not run mixed runtime versions against the same checkout: different lock names cannot coordinate writes. |
| Prototype cookies and trusted IP header | `civic-spark-prototype.*`, `x-civic-spark-client-ip` | Prototype users must sign in again. Verified-email cookies keep Better Auth's existing prefix. The server overwrites the trusted IP header; never trust a client-supplied value. |
| Browser preferences | `civic-spark:workspace:<id>:agent`, `:explorer`, `:tab`; picker ID `civic-spark-workspace` | Earlier preferences will not load automatically. Saved runtime conversations and credentials are separate from browser preferences. |
| Folder sync baseline | `.civic-spark-sync.json` | Back up the connected folder and preserve its workspace binding and baseline before translating the marker. Do not reconnect an old folder as empty state or approve transfers until reconciliation is reviewed. |
| Editor test switches | `CIVIC_SPARK_EDITOR_DEV`, `CIVIC_SPARK_EDITOR_BLOCK_HTML` | Update local test invocations and CI variables. |

Before cutover, take coordinated private backups of database/auth stores, shared and personal repositories (including untracked files and all refs), connected local folders and Sprite runtime/native provider state. Retain the original revision and backups for rollback. Do not remove earlier markers or recovery paths until post-migration checks pass.

Rehearse on dedicated disposable resources without paid inference. Verify identity/team ownership, exact Git HEAD/baseline/recovery refs, unchanged file hashes, saved-key presence, conversation/session continuity, browser and terminal reconnect, folder-sync reconciliation, private preview and explicit Share semantics before enabling participant access. Physical device and live provider verification remain separate work. Historical evidence in this repository describes its original revision and is not proof of compatibility after the rename.
