## Failures

**Eight Share refusals, one cause.** p05, p07, p15, p17, p20, p31, p34 and p47 all reached the MVP Share, the Sprite committed and bundled successfully every time, and the host refused the contribution with "The committed history includes excluded files" four times in a row. Each of those workspaces had committed `.oxlintrc.json` (at the project root or under `app/`), written by the Vite scaffold the agent used. The path policy treated every hidden file except `.gitignore` as private and applied that to the whole committed history, so the only way out would have been rewriting the agent's commit. Passing workspaces simply had no hidden files. Yesterday's run with the same prompt passed 48 of 50, so the scaffold or model output changed, not the platform; the policy was too strict for real projects.

**One harness timing miss.** p41 saved `hello.txt` (the blob write returned 200 at 19:07:56, in the busiest minute) but the runner did not see the editor toolbar show the file within 30 s and stopped. No error response was involved. Same class as earlier single-runner misses; not a platform failure.

## Change made

Hidden paths are now project data unless they are private or machine state. The "no dotfiles except `.gitignore`" rule in TypeScript and both Sprite Python helpers became a denylist: `.env` and `.env.*` (except `.env.example`, `.env.sample`, `.env.template`), `.npmrc`, `.yarnrc`, `.netrc`, `.pypirc`, `.ssh`, `.aws`, `.gnupg`, `.docker`, `.kube`, `.civic-spark-agent`, `.civic-spark-sync.json`, `.claude`, `.opencode`, `.codex`, `.DS_Store`, cache directories, plus the existing `credentials/`, `secrets/`, `node_modules/`, key, certificate and log extensions. `.github/`, `.vscode/`, `.editorconfig`, lint and format configuration and the rest are committed and shared like any other file. A refused Share now names the excluded paths. Parity tests were rewritten around the new rule.

With this policy the eight refused workspaces would have shared normally, which would have made the run 49 of 50.
