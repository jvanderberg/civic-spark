## What still costs the most

1. **Child processes**: ~3 long-lived per person (helper session, terminal PTY, agent runner) plus transients, 147 at peak. Terminals stay attached because the runner keeps the tab open; real participants will too.
2. **Agent streaming fan-out**, now batched at 50 ms, still ~50 concurrent streams through one loop.
3. **Per-person polling routes** (preview, agent-git, files, file) at 15–20 s cadence still dominate request counts.

Next candidates from the audit, in order: move terminal and agent stream relays into a bridge process (the single-loop ceiling), cut the preview/agent-git polls to push or longer intervals, and cap the `changes` payload.
