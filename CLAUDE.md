# Civic Spark instructions for Claude

@AGENTS.md

`AGENTS.md` is the shared contributor policy for Codex and Claude. Read and follow it before changing this repository, together with `docs/product.md` and `IMPLEMENTATION_PLAN.md`. Keep new contributor requirements there so the two agents follow the same rules.

Mobile support is a release requirement for every participant and admin UI change. Verify touch and keyboard access, narrow and short viewports, reachable forms/dialogs/actions, internal panel scrolling, and system light/dark appearance. Preserve unsaved work and ongoing sessions when layouts change. Run the relevant browser checks, inspect their actual screenshots and console errors, and run `npm run check` before reporting completion. The terminal may remain awkward on phones; unsupported native folder pickers need the existing browser-editing/upload/download fallback. Do not claim real-device verification from viewport emulation.
